Materiais necessarios para criar uma pagina HTML:

  • Computador ou notebook
  • Editor de código, como o Visual Studio Code
  • Navegador de internet
  1. Abrir o editor de codigo e criar um arquivo HTML.
  2. Adicionar a estrutura basica do HTML e inserir os conteúdos.
  3. Salvar o arquivo e abrir no navegador para verificar o resultado.
